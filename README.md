# Система управления климатом в погребе

## Описание проекта

Система управления погребом представляет собой Arduino-устройство на базе Arduino Nano, предназначенное для автоматического контроля климата в подвале или погребе. Система использует различные датчики для мониторинга температуры, влажности и других параметров, а также управляет вентиляцией и озонированием для поддержания оптимальных условий хранения продуктов.

## Основные функции

### Климат-контроль
- Автоматическое управление вентиляцией для поддержания заданной температуры (4°C) и влажности (85%)
- Использование алгоритма сравнения абсолютной влажности внутри и снаружи помещения
- Защита от образования конденсата

### Озонирование
- Автоматический цикл озонирования по расписанию (раз в неделю в 02:00)
- Трехфазный цикл: активное озонирование (15 мин) → пауза (2 часа) → проветривание (15 мин)
- Проверка условий безопасности перед запуском (температура на улице > 0°C, отсутствие подсветки)
- Защита от повторных попыток при неблагоприятных условиях (ожидание 30 минут)

### Мониторинг и управление
- Отображение данных с датчиков на LCD-экране (16x2)
- Интерфейс управления с кнопками (вверх, вниз, меню)
- Возможность ручного запуска вентиляции и озонирования
- Система диагностики и обработки ошибок

### Безопасность
- Контроль критических параметров (температура, влажность, точка росы)
- Аппаратная защита с использованием сторожевого таймера (Watchdog)
- Блокировка опасных операций при возникновении ошибок

### Основные компоненты

#### Controller
- Основной контроллер системы с FSM (машина конечных автоматов)
- Обрабатывает все состояния системы: `AUTO_CLIMATE`, `OZONE_START`, `OZONE_ACTIVE`, `OZONE_HOLD`, `OZONE_VENT`, `MANUAL_FAN`, `MANUAL_OZONE`, `ERROR_STATE`
- Интегрирует данные от всех модулей и принимает решения об управлении

#### SensorManager
- Управление датчиками: BME280 (внутренние параметры), HTU21D (уличные параметры), DS18B20 (контрольная температура подвала)
- Применение фильтров (медианный + EMA) для сглаживания показаний
- Диагностика состояния датчиков и обнаружение ошибок

#### RelayManager
- Управление твердотельными реле для вентилятора и озонатора
- Защита от дребезга (5-минутная задержка для вентилятора)
- Функция принудительного отключения в аварийных ситуациях

#### DisplayUI
- Интерфейс пользователя с LCD-дисплеем (16x2) и кнопками
- Несколько страниц отображения: внутренние/уличные параметры, состояние реле, ручные режимы
- Автоматическое отключение подсветки через 30 секунд бездействия

#### TimeManager
- Работа с RTC DS3231 для точного времени и расписания
- Обработка расписания озонирования
- Диагностика состояния часов

#### MathUtils
- Реализация фильтров для сглаживания данных с датчиков
- Расчет абсолютной влажности и точки росы
- Математические функции для климатических расчетов

## Требования к установке

### Аппаратные требования
- Arduino Nano (ATmega328P)
- Датчики:
  - BME280 (внутренние параметры)
  - HTU21D (уличные параметры)
  - DS18B20 (контрольная температура)
- RTC DS3231 (часы реального времени)
- LCD 16x2 (I2C)
- Кнопки (вверх, вниз, меню)
- Реле (вентилятор, озонатор)
- Сторожевой таймер (встроенный в Arduino)

### Зависимости
Для сборки проекта необходимы следующие библиотеки:
- Adafruit BME280 Library (^2.3.0)
- Adafruit Unified Sensor (^1.1.15)
- Adafruit HTU21DF Library (^1.1.2)
- DallasTemperature (^4.0.5)
- OneWire (^2.3.8)
- RTClib (^2.1.4)
- LiquidCrystal (^1.0.7)

## Настройка и запуск

### Платформа разработки
Проект использует PlatformIO для сборки и загрузки прошивки. Конфигурация находится в файле `platformio.ini`.

### Конфигурационные параметры
Все основные параметры находятся в файле `Config.h`:
- Пин-аппаратное соответствие
- Целевые значения температуры и влажности
- Гистерезисные значения
- Временные интервалы
- Критические параметры

### Процесс запуска
1. Подключите все датчики и периферийные устройства согласно схеме подключения
2. Установите зависимости через PlatformIO
3. Соберите проект: `pio run`
4. Загрузите прошивку: `pio run --target upload`
5. Откройте монитор последовательного порта для просмотра отладочной информации (при включенном `DEBUG`)

## Finite State Machine (FSM)

Система использует машину конечных автоматов для управления различными режимами работы:

- `IDLE`: Режим ожидания
- `AUTO_CLIMATE`: Автоматический контроль климата
- `OZONE_START`: Подготовка к озонированию (проверка условий)
- `OZONE_ACTIVE`: Активное озонирование (15 минут)
- `OZONE_HOLD`: Пауза после озонирования (2 часа)
- `OZONE_VENT`: Проветривание помещения (15 минут)
- `OZONE_ABORT`: Прерывание цикла озонирования
- `MANUAL_FAN`: Ручной режим вентиляции
- `MANUAL_OZONE`: Ручной режим озонирования
- `ERROR_STATE`: Состояние ошибки (все реле выключены)

FSM обеспечивает корректную реакцию системы на изменение условий и позволяет безопасно переходить между различными режимами работы.

## Безопасность и надежность

Система включает несколько уровней защиты:
- Контроль целостности датчиков
- Защита от рассинхронизации показаний разных датчиков
- Критические проверки температуры и влажности
- Аппаратный сторожевой таймер для предотвращения зависания
- Принудительное отключение при аварийных ситуациях
